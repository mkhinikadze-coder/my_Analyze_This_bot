# თვითანალიზის ტელეგრამ-ბოტი 🙏

უფასო, მრავალენოვანი (ქართული/რუსული/ინგლისური) ტელეგრამ-ბოტი დღიური თვითანალიზისთვის.

## რას აკეთებს

1. მომხმარებელი ირჩევს ენას.
2. ეჩვენება ლოცვა და „დაწყება“ ღილაკი (+ ინფო, რომ ანალიზი 15 წუთში წაიშლება).
3. 9 კითხვა ერთმანეთის მიყოლებით (თითოეულთან „გამოტოვება“ ღილაკი), ყოველი ახალი კითხვის თავზე ჩანს წინა კითხვა-პასუხები.
4. ბოლო კითხვის შემდეგ ორი ღილაკი: „დასრულება“ ან „AI-ს ანალიზი“.
5. „AI-ს ანალიზი“ პასუხებს უგზავნის Google Gemini-ის **უფასო** API-ს, რომელიც აბრუნებს თბილ, მხარდამჭერ უკუკავშირს (12-ნაბიჯიან პროგრამაზე დაფუძნებული, მაგრამ ეს არსად ჩანს პასუხში).
6. 15 წუთის შემდეგ ბოტი თავად შლის ანალიზის შეტყობინებას და მომხმარებლის პასუხებს — თუ წინასწარ არ დააჭირა „💾 შენახვა ჩემთვის“-ს (მაშინ ცალკე, წაუშლელი შეტყობინებით ინახება).
7. `/reminder` — ყოველდღიური შეხსენების ჩართვა/გამორთვა (ნაგულისხმევად 21:00).
8. `/stats` — რამდენჯერ დაასრულა ანალიზი (მხოლოდ რიცხვი, პასუხების შინაარსის გარეშე).

## რატომ ეს არჩევანი — 100%-ით უფასო

- **ტელეგრამ ბოტის API** — მუდამ და სრულად უფასოა.
- **Google Gemini API** (`gemini-2.5-flash` მოდელი) — აქვს მუდმივი უფასო tier, ბარათის მიბმის გარეშე (დღეში საკმარისი ლიმიტი პირადი ბოტისთვის). სხვა ვარიანტებისგან (Claude/OpenAI) განსხვავებით, არ საჭიროებს გადახდის მეთოდის მითითებას.
- **ჰოსტინგი** — Render.com-ის ან Railway-ის უფასო tier საკმარისია მცირე პირად ბოტზე.

## 1. მოამზადე Telegram Token

1. ტელეგრამში მოძებნე **@BotFather**.
2. გაუგზავნე `/newbot`, აირჩიე სახელი და username (`...bot`-ით დამთავრებული).
3. დაგიბრუნებს **token**-ს — გადაინახე.

## 2. მოამზადე Gemini API Key (უფასო)

1. გადადი: https://aistudio.google.com/app/apikey
2. შედი Google ანგარიშით და დააჭირე „Create API key“.
3. დააკოპირე key — ბარათი არ სჭირდება.

## 3. გაშვება საკუთარ კომპიუტერზე (ტესტისთვის)

```bash
cd selfanalysis_bot
python3 -m venv venv
source venv/bin/activate        # Windows-ზე: venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env
# გახსენი .env და ჩაწერე შენი TELEGRAM_BOT_TOKEN და GEMINI_API_KEY

python bot.py
```

ტელეგრამში მოძებნე შენი ბოტი და დააჭირე `/start`.

## 4. უფასო 24/7 ჰოსტინგი (Render.com მაგალითი)

1. ატვირთე ეს ფოლდერი GitHub-ის საცავში (repo).
2. შედი https://render.com და დააკავშირე GitHub ანგარიში.
3. **New +** → **Background Worker** → აირჩიე შენი repo.
4. **Build Command:** `pip install -r requirements.txt`
5. **Start Command:** `python bot.py`
6. **Environment** ჩანართში დაამატე:
   - `TELEGRAM_BOT_TOKEN`
   - `GEMINI_API_KEY`
7. აირჩიე **Free** გეგმა და დააჭირე **Create Background Worker**.

(Railway-ზეც ანალოგიური პროცესია: New Project → Deploy from GitHub → Variables-ში დაამატე იგივე ორი გასაღები.)

> ⚠️ შენიშვნა: Render/Railway-ის უფასო tier-ებს ზოგჯერ აქვთ დროებითი „ჩაძინების“ ან გადატვირთვის პერიოდები — უფასო ბოტისთვის ეს ჩვეულებრივ პრობლემა არაა, უბრალოდ იცოდე, რომ 100%-იანი გარანტირებული uptime მხოლოდ ფასიან გეგმებზეა.

## ფაილების სტრუქტურა

```
selfanalysis_bot/
├── bot.py            # მთავარი ლოგიკა, ყველა ღილაკი და ბრძანება
├── texts.py          # ყველა ტექსტი 3 ენაზე + კითხვები + AI prompt
├── ai_client.py       # Gemini API-სთან დაკავშირება
├── requirements.txt
├── .env.example
└── Procfile          # Render/Railway-სთვის
```

## რისი შეცვლა შეგიძლია მარტივად

- **კითხვების ტექსტი** — `texts.py`-ში, `QUESTIONS` ლექსიკონში.
- **ლოცვის ტექსტი** — `texts.py`-ში, `PRAYER`.
- **წაშლის დრო (ახლა 15 წთ)** — `bot.py`-ში, `DELETE_AFTER_SECONDS`.
- **შეხსენების საათი** — `.env`-ში `REMINDER_HOUR` / `REMINDER_MINUTE`.
- **AI-ს „ხასიათი“** — `texts.py`-ში, `build_ai_prompt()` ფუნქცია.

## კონფიდენციალურობის შესახებ

პასუხების ტექსტი არსად ინახება მუდმივად (garbage collect-დება 15 წუთში), გარდა იმ შემთხვევისა, როცა მომხმარებელი თავად დააჭერს „შენახვა ჩემთვის“-ს — მაშინაც კი, ის რჩება მხოლოდ ტელეგრამის ჩატის ისტორიაში, არა ბოტის სერვერზე. სერვერზე მუდმივად ინახება მხოლოდ: ენის არჩევანი, შეხსენების ჩართული/გამორთული სტატუსი და დასრულებული ანალიზების რაოდენობა (რიცხვი).
